course web site instructions

  • Here is: the link to the main course page.
  • The page consist of a navigation header with a particular course page in the frame below.
  • Click on the dropdown at the upper left corner of the navigation header to go directly to any page.
  • In most broswers there is a way to click to open the framed page in a new tab, without the navigation header.
    • In Safari: right-click while viewing the page and select “Open Frame in New Tab”.
    • In Chrome: this feature is avaiable in older version of Chrome. In newer version, one must install an “Open Frame in New Tab” extension.
  • External links that the course points to open in a new tab.
  • Internal links to a page in the dropdown list open in the same tab, with the selection in the navigation dropdown changed.
    • In most browswers, this can be overriden by right-clicking on the link and selecting “open link in new tab”.
      • This bring up the page without the navigation header.
  • Internal links to a page not in the dropdown list open in a new tab.
  • Pretty much all pages on the web site also have a pdf version, which can be viewed on the web by changing the extension of the URL from ‘.html’ to ‘.pdf’.
