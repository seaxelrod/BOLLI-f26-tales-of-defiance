Prelude: This Course Survived a Literal Glitch in the System

While building the pdf for the preface of this system (out of the “markdown” file that I write), the code engine kept throwing a cryptic warning: “missing character.”

Did you ever wonder how the winking in and out of the matrix of the main characters could have gone so unnoticed by ordinary citizens? Well, I completely ignored explicitly being warned of missing characters beacuse what I cared about, the finished PDF, looked completely flawless.

I had no idea there was a “ghost” sub-process quietly running in the background, secretly duplicating data into a hidden architectural layer and silently crashing the engine.

It was only when I was deep into adding new features to the code and running a routine “sanity check” that I finally stopped to investigate the warning.

To find the truth, I had to halt the system and read the raw crash log, learning firsthand what Neo did: the seamless reality we accept at face value is often just an illusion hiding the ghosts in the machine.

The ghost processes still run in the background when I build the course files, but I have told them to translate the characters they stumbled on in a way that won’t confuse them. So they no longer cry out with evidence of a glitch.

So, I guess I am the architect that is trying to keep up appearance so that you, the class, are not disturbed.

Except, just now, I gave you a tiny dose of a red pill trip.
