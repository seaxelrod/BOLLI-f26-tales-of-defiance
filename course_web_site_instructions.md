- Here is: [the link to the main course page](https://seaxelrod.github.io/BOLLI-f26-tales-of-defiance/).
  - The page consist of a navigation header with a particular course page in the frame below.

- The dropdown at the upper left corner of the naviagion header points to the top-level pages of the course.
   - Selecting a page in the dropdown display that page in the main course page frame. 
    - In most broswers there is a way to click to open the framed page in a  new tab, without the navigation header.
       - In Safari:   right-click while viewing the page and select "Open Frame in New Tab".
       - In Chrome: this feature is avaiable in older version of Chrome. In newer version, one must install an "Open Frame in New Tab" extension. 

- Here is what happens when you click on a link in a framed page:
  - External links (not within the course website) open in a new tab.
  - Internal links to a page in the dropdown list that don't point to a particular place inside the page (called an "anchor") open in the same tab, with the selection in the navigation dropdown changed.
  - Internal links to a page not in the dropdown list or links to a page in the dropdown list with an anchor open in a new tab.
     - This bring up the page in a new tab without the navigation header.

- Pretty much all pages on the web site also have a pdf version, which can be viewed on the web by changing the extension of the URL from '.html' to '.pdf'.
